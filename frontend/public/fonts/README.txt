Fonts served by this site (self-hosted; no third-party font host)

csd-sans-400.woff2, csd-sans-600.woff2, csd-sans-400-italic.woff2
  Subsets of IBM Plex Sans 1.1.0 (Regular, SemiBold, Italic), from the
  @ibm/plex-sans package published by IBM. License: LICENSE-IBM-Plex-Sans.txt
  (SIL Open Font License 1.1).

csd-serif-600.woff2
  Subset of Source Serif 4 Subhead Semibold, version 4.005, from Adobe's
  release at github.com/adobe-fonts/source-serif. License:
  LICENSE-Source-Serif-4.txt (SIL Open Font License 1.1).

Each file is cut down to Latin text, punctuation, arrows and a few math signs
(fontTools pyftsubset, WOFF2). Because a subset is a Modified Version under
the OFL, the families are renamed "CSD Sans" and "CSD Serif" and do not use
the Reserved Font Names "Plex" and "Source". The copyright and license
records are kept in each file's name table.
